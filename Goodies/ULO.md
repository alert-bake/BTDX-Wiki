# U.L.O.

**Category:** Gameplay goodie  
**Goodie slot:** 14  
**In-game description:** “Unidentified Laughing Object” / “Gives Extra Cash at start”  
**Unlock cost:** 1 Goodie Token

When equipped, one U.L.O. is spawned as the game begins. The spawn script only does this once per run.

The store describes the reward as extra starting cash. The inspected Goodie code confirms the one-time U.L.O. spawn, but does not establish the exact cash amount or how the object awards it.
