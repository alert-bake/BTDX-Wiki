# Bloons Tower Defense X

**Bloons Tower Defense X (BTDX)** is a fan-made tower-defense game created by RamafParty. It builds on the Bloons Tower Defense formula: place towers, upgrade them, and stop waves of Bloons from reaching the end of a track.

## At a glance

- **Creator:** RamafParty
- **Genre:** Tower defense
- **Original platform:** Windows
- **Engine:** GameMaker Studio 2
- **Android version documented by this wiki:** Unofficial port 1.5.2, edited for Android by Albiot1
- **Original developer's download page:** [Ramaf Party — Bloons TDX](https://www.ramafparty.com/btdx.html)

## What makes BTDX different?

The original developer's feature list describes:

- 24 towers, each with four upgrade paths
- More than 30 tracks with multiple play modes
- 13 special missions
- New Bloon types
- More than 200 achievements

These are the developer's published feature claims; individual pages in this wiki should document the exact mechanics and content rather than relying on this summary.

## Basic objective

BTDX is a tower-defense game. The player uses towers to pop incoming Bloons before they escape along the track. Escaped Bloons cost lives; losing all available lives ends the run.

## Versions and platforms

This wiki uses **Android port version 1.5.2** as its primary reference build unless a page explicitly names another version.

Do not treat the Android port and the original Windows release as interchangeable:

- The original developer's site currently lists Windows version 1.5.1.
- The Android release is an unofficial adaptation credited to Albiot1 and is listed as version 1.5.2.
- A version number alone does not prove that every platform has identical content, controls, or bugs.

The Android 1.5.2 release notes list fixes for Bloonberry Bush crashes after leveling, occasional Monkey God upgrade crashes, and Sniper targeting, along with Android API and graphics/hitbox changes. See [the Android 1.5.2 release listing](https://apkpure.net/btd-x/btdrrx.RamafpartyxAlbiot1) for the third-party changelog. Treat third-party release notes as a source to verify, not as a substitute for testing.
