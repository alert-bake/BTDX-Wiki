# Planetarium Bloon

<badge>Research draft</badge>

## Overview

Planetarium Bloons release orbiting Satelite Bloons that distract towers and block projectiles. When destroyed, a Planetarium Bloon reportedly releases twelve Satelites and a Comet Bloon. A larger pink second tier releases stronger children.
