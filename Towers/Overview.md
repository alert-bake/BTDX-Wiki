Towers are the player's main way of defending against Bloons in Bloons Tower Defense X (BTDX). Most towers attack Bloons directly, while a small number focus on economy or support. Towers can be upgraded to improve their performance and unlock different roles.

This page is an overview of the tower roster and upgrade system. Detailed statistics, prices, targeting rules, and upgrade effects belong on individual tower pages and should be recorded with the game version they were checked against.

## Tower roles

Towers do not all serve the same purpose:

- **Direct attackers** damage Bloons using their own attacks.
- **Support towers** improve or assist other towers rather than relying only on direct damage.
- **Economy towers** help generate money for the player.
- **Hybrid towers** can gain additional offensive or support functions through upgrades.


## Upgrade system


- **Left (L)**
- **Middle (M)**
- **Right (R)**
- **Stacked (S)**, also called **Alt (A)**

The base tower is tier 0. Upgrade shorthand combines the tier number and path letter: for example, **3L** means the third tier on the Left path.

### Initial upgrades


- Tier 1
- Tier 2
- Tier 3 Left
- Tier 3 Middle
- Tier 3 Right

Higher upgrades are unlocked through progression using Bloon Points. The exact unlock requirements can vary by tower.

### Stacked upgrades

The Stacked path is the fourth path. Its upgrades are commonly written as **3S, 4S, and 5S**; some sources use **3A, 4A, and 5A** for the same path.


1. Unlock all upgrades on a required main path. The required path differs between towers.
2. Complete a Bounty using only that tower. The wiki gives Dart Monkey's Middle path as one example of a required path.
3. After the Stacked path is unlocked, upgrade the tower to tier 2.
4. Attempt to place another copy of the same tower on top of it. This reveals the Stacked-path choice in the upgrade area.
5. Once the tower reaches tier 3 on the Stacked path, tiers 4 and 5 can be purchased normally.

The exact unlock requirement should be checked on the relevant tower's page rather than assumed to be identical for every tower.
